South Dakota Answer Plots

Description

This webpage is a rough draft that I plan to use for my summer SRT project, if possible. Below are some of the features I intend to include:

  • Pins placed at each Answer Plot location.
  • Clicking or tapping a pin will zoom in to the corresponding Answer Plot.
  • Each Answer Plot will display a bird’s-eye view of the field with a simplified treatment/showcase overlay and text labels.
  • An optional NDVI view of the field using imagery from drone flights.
  • An optional “user location” feature so visitors can see where they are within the field.

Each location will have a QR code that visitors can scan with their phone to access this webpage while walking around the Answer Plot. I used an older NDVI map from one of my fields in Minnesota as an example of what I plan to create (feel free to click on the pin near Rochester, MN to see). Because this was a regular field, I added some example treatment squares to demonstrate the concept (the final version would also include labels for each treatment).

Plot maps will be created using ArcGIS Pro.
