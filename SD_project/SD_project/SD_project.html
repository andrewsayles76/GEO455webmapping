South Dakota Answer Plots

Description

This is my rough draft webpage that (if I can) I will use for my summer SRT project. Here are some of the things I plan on doing

  • Have pins at each Answer Plot
  • Click/tap on the pins I will zoom into Answer Plots
  • Answer Plot locations will show bird eyes view of the crops with a simplified treatment/showcase overlay (with text labels)
  • I plan on also having an optional NDVI view of the field (from drone flights)
  • There is an optional “user location" so someone can see where they are in the field

Each location will have a QR code that someone can scan with their phone and use this webpage while they’re walking around on the Answer Plot. I had an old NDVI map of one of my fields in Minnesota to show an example of what I plan on doing. Because this is just normal field I drew on some fake treatment squares (I would also have labels for each treatment).
